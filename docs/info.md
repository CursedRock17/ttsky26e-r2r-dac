## How it works

8-bit R-2R resistor-ladder DAC in SKY130, running from the 3.3 V analog supply (VAPWR). Digital code D0-D7 on ui_in[7:0], analog output on ua[0].

## How to test

Drive a code on ui_in[7:0] and measure VOUT on ua[0] with a scope or DMM.

## External hardware

Scope or DMM on the analog output.
